Software-defined radio receiver

A MATLAB receiver that decodes corrupted radio recordings back into text.

A project for my Communication Systems course. We were given three recorded radio signals, each damaged in different ways, and had to write a receiver in MATLAB that turned them back into readable text. Mine decoded all three.

How it works

The receiver works in stages. It filters out interference, locks onto the carrier, finds the right moment to sample each symbol, corrects for distortion with an adaptive equaliser, and finds where each block of data starts. Some stages started from the course textbook's example code, which I adapted and combined with my own.

A difficult bug

The decoded text alternated between correct and unreadable on every other block. The stage that locks onto the carrier can lock on upside down, which flips every symbol. I fixed it by checking each block against its known header and flipping it back when needed.
