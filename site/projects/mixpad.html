Pico MixPad

A USB controller for setting Windows volume per application.

I wanted a quicker way to balance game, voice chat and music than opening the Windows volume mixer, so I built a controller for it. It has a main volume knob, four knobs for individual apps, eight mechanical keys and a small screen that shows what each knob controls. Pressing any knob mutes it, and one key mutes the microphone.

How it works

The pad connects over USB and appears as a keyboard, a media controller and a serial port at the same time, so the main volume knob and media keys work on any computer with nothing installed. A Python app on the PC adds per-app control through the Windows audio API and communicates with the pad over a simple text protocol I designed.

The firmware is written in CircuitPython, and the Pico's programmable I/O reads the knobs in hardware so no steps are missed. The knobs send how far they were turned rather than a fixed position, so changing a volume in Windows never fights the hardware. The desktop app has 22 unit tests that run without the pad attached, on every push to GitHub.

Serial messages

FromMessageMeaning
PC?Is a pad connected?
PadHELLO MACROPADYes, with its version
PadE ch deltaA knob was turned
PadP chA knob was pressed
PCV ch vol muted labelWhat to show for a knob
PCMIC 1|0Mic state, for the light

The PC repeats the full state every second. If the pad receives nothing for five seconds, it continues as a plain volume controller.

Build

The case is a 3D-printed plate and tray, generated from one parametric OpenSCAD file. The switches and knobs are hand-wired with jumper leads that plug onto the Pico's header pins, so nothing is soldered to the Pico itself and it can be reused on the planned circuit board.

Next steps

A custom circuit board with hot-swap key sockets instead of hand wiring, and a C++ version of the desktop app to replace the Python one.
