Virtual reality card game

A card duel you play with your hands in VR.

A team project for the Innovative Technologies course. Four of us built Magic Mayhem, a card duel game in virtual reality, with Unity and Oculus XR. You stand at a table, physically pick up cards and play them against a computer opponent.

The project got a 1.3, the highest grade in the class.

Improvements since the course

The game logic was one large script that also spawned cards, played sounds and updated the score. The rules (elements, the deck, rounds and scoring) are now a separate C# library with no Unity code, covered by 15 NUnit tests. The tests run in Unity and also on GitHub Actions, without a Unity licence.

Several bugs are fixed. A card released anywhere was played if it had touched the table spot earlier, a played card could be picked up and played again, and a tied match ended with an error message. The computer is now dealt its own hand like the player, a tie goes to extra rounds, and each round says why it was won or lost.
